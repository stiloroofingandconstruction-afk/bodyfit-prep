# BodyFit Prep

1. Crea un repositorio en GitHub llamado `bodyfit-prep`.
2. Sube todos estos archivos a la raíz.
3. En Vercel: Add New > Project > importa el repositorio.
4. Framework Preset: Other.
5. Deja Build Command y Output Directory vacíos.
6. Deploy.
7. Abre el enlace en Safari > Compartir > Añadir a pantalla de inicio.
